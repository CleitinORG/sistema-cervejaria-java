# 🍺 PampaBrew

Sistema desktop em Java para gerenciamento e avaliação de cervejas.

## 🚀 Funcionalidades

* Cadastro de cervejas
* Avaliação e comentários
* Registro de degustações

## 🛠 Tecnologias

* Java (Swing)
* MySQL

## ▶️ Como executar

1. Importar no Eclipse/IDE
2. Configurar banco de dados
3. Executar aplicação

## 🎯 Objetivo

Prática de desenvolvimento desktop com Java.
